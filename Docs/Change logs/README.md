# Change logs

Record of notable changes to EduTrack over time.

## Purpose

Keeps a chronological history of features, fixes, and breaking changes so the
team can track how the project evolved.

## Conventions

- One file per release or period (for example `2026-11.md`).
- Group entries under `Added`, `Changed`, `Fixed`, and `Removed`.
- Newest entries first.

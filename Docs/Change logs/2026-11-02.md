# 2026-11-02

## Added

- `infrastructure/docker-compose.yml` with `frontend` and `backend` services, shared bridge network, and env-driven ports/tags.
- `infrastructure/.env` holding image tag, backend/frontend ports, ASP.NET environment, and `VITE_API_BASE_URL`.
- Frontend `Dockerfile` build arg `VITE_API_BASE_URL` so the API base URL is baked in at build time.

## Changed

- Frontend container is wired to call the backend via `VITE_API_BASE_URL` (defaults to `http://localhost:8080`).

## Notes

- Backend `Program.cs` still has no CORS policy; browser calls to the backend will be blocked until CORS is enabled or requests are proxied same-origin.
